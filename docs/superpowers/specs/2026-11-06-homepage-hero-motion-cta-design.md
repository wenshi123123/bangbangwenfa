# 首页首屏动效与咨询入口设计

## 目的

强化首页首屏的叙事节奏和点击吸引力，让用户先理解“AI 千问，不如律师一言”的价值主张，再清楚地进入民事或刑事咨询。整体保持帮帮问法现有的温暖、克制和专业气质，不做科技炫技或电商式强促销。

## 已确认选择

- 标题动效：A「叙事式逐层揭示」。
- 咨询入口：编辑式入口增强版 A「色块推入」。
- 色彩与字体：沿用现有品牌色和字体体系，不引入新的视觉主题。

## 目标

- 首次进入首页时，用一次约 1.8 秒的编排建立标题、正文、承诺信息的阅读顺序。
- 让“律师一言”成为标题中的视觉落点。
- 将民事咨询和刑事咨询改为两个等权重、整块可点击的编辑式入口。
- 通过明确的悬停、键盘聚焦和按压反馈，让入口既高级又具有强点击暗示。
- 在移动端保持入口清晰、触控区域充足，并尊重系统的减少动画设置。

## 非目标与反目标

- 不改变现有咨询路由、登录逻辑或右侧图片轮播逻辑。
- 不加入打字机、逐字弹跳、大量粒子、持续缩放或强视差。
- 不让刑事咨询被设计成次要入口，也不使用会制造恐慌的警告色。
- 不让首屏动画反复循环；页面加载完成后保持稳定。

## 视觉与交互规格

### 1. 叙事式标题入场

动画仅在首屏初次挂载时播放一次：

1. `AI 千问` 在约 80ms 后开始，由下方 18px 上移，同时从轻微模糊和透明过渡到清晰，时长约 700ms。
2. `不如` 在约 350ms 后从左侧 12px 淡入，时长约 650ms。
3. `律师一言` 在约 550ms 后通过从左到右的遮罩揭示，时长约 780ms；完成时从约 1.015 倍轻微回落到正常比例。
4. 两行正文分别在约 1020ms 和 1180ms 后轻微上浮淡入。
5. `180秒 / 30分钟 / 3小时` 承诺信息在约 1430ms 后整体上浮淡入。
6. 标题动画完成后不循环；现有背景呼吸与右侧轮播保持独立运行。

### 2. 编辑式色块推入入口

- 原有胶囊按钮改为两个等宽入口，桌面端横向排列，移动端纵向排列。
- 每个入口包含服务名称、简短说明和右上方向箭头，不显示额外编号。
- 整个入口区域均为链接，不仅文字和箭头可点击。
- 默认态使用暖白背景、细陶土色边框和较大的留白，保留编辑排版气质。
- 民事咨询悬停时，陶土橙色从左向右覆盖整个入口；刑事咨询使用品牌深棕色覆盖。
- 覆盖过程中标题和说明切换为白色，圆形箭头切换为白底并轻微右移、旋转，过渡约 300–420ms。
- 键盘聚焦时提供清晰但克制的外轮廓；触屏设备使用短暂按压态，不依赖悬停才能理解入口。
- 正式文案：
  - 民事咨询：`合同、婚姻、债务与日常权益`
  - 刑事咨询：`拘留、取保、辩护与刑事风险`

## 响应式与可访问性

- 桌面端两个入口并排，保持等权重。
- 小屏幕下改为上下排列，单个入口最小触控高度不低于 72px。
- 使用语义化链接并保留清晰的键盘焦点状态。
- 现有全局 `prefers-reduced-motion: reduce` 规则继续生效；减少动画模式下直接显示最终状态。
- 动画只改变 `opacity`、`transform`、`clip-path` 等视觉属性，避免引起布局跳动。

## 实现约束

- 修改范围主要为 `src/app/page.tsx` 与首页所需的局部样式。
- 优先使用 CSS 动画和现有 Tailwind/CSS 能力，不新增动效依赖。
- 使用项目已有的 Lucide 箭头图标。
- 保留现有 `getCivilUrl()`、`getConsultUrl()` 和 `prefetch={false}` 行为。

## 备选方案与取舍

- 标题曾比较叙事式揭示、AI 残影对比和落墨书写；选择叙事式揭示，因为它最稳重，且不会让法律服务显得过度科技化或传统化。
- 入口曾比较双案卷、主次通道、分段选择和编辑式文字入口；选择编辑式入口作为基础，因为它与首屏宋体标题最协调。
- 编辑式入口又比较色块推入、行动圆标和错位纸页；选择色块推入，因为它的点击反馈最强，同时仍保留编辑排版骨架。

## 验收标准

- 首次打开首页时，标题、正文和承诺信息按上述顺序完成一次入场。
- 页面稳定后不存在持续的标题循环动画。
- 民事与刑事入口在桌面端和移动端均清晰可见、整块可点击、路由保持正确。
- 鼠标悬停、键盘聚焦、触屏按压和减少动画模式均有合理表现。
- 改动不影响右侧轮播、现有咨询流程或其他首页区块。
